# Memory conventions

Use typed OKF 0.2 concepts, honest actors, offset-aware timestamps, standard
Markdown links, and exact source-footnote IDs. Preserve unknown metadata and
history. Do not fabricate sources or verification.

Local capture follows explicit enablement. Shared content requires deliberate
promotion. Store metadata is outside root OKF frontmatter. No helper command
stages, commits, pushes, deletes, installs dependencies, or resolves evidence
contradictions on its own.
